# Molecular Orbital PACkage (MOPAC) with PM6-FGC approach

[![License: LGPL v3](https://img.shields.io/badge/License-LGPL_v3-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0)

## Branch description

This branch follows the main branch but adds the interface to the [MOPAC-FGC wrapper](https://github.com/OmarRodriguezLopez1398/mopac_fgc), which provides the functional groupcorrections for PM6 calculations. Information on how to run the calculations is provided there; this branch of MOPAC provides just the executable that MOPAC-FGC depends on.

For more information on MOPAC and instructions on compilation, see the README of the [main](https://github.com/OmarRodriguezLopez1398/mopac) branch.
